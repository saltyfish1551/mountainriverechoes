# 高山族音乐的系统研究

**项目**：山河回响（mountainriverechoes）· 中国 56 民族音乐曲库
**负责人**：张紫晗（高山族）
**成稿日期**：2026-10-09
**协作方式**：人工选题、判断与复核 + AI 辅助检索、统计与撰稿（依课程要求）

> 说明：本文所称「高山族」，指中国 56 个民族之一、世代居住在台湾地区的少数民族；其内部包含阿美、泰雅、排湾、布农、卑南、鲁凯、邹、赛夏、雅美（达悟）等多个支系。台湾地区文献中另有「原住民族」「高砂族」等称谓，大陆学界与《中国少数民族音乐史》等权威著作长期通行「高山族音乐」的称法，本文依此为准，支系名沿用各族自称。

## 一、高山族音乐的总体概况

### 1.1 以歌唱为主体，器乐为辅助

高山族音乐的主体是**声乐**，器乐处于辅助地位。这一特征与其所处地理环境直接相关：岛上可得的乐器材料有限，乐器多取自天然物（竹、木、兽皮、金属片），故「随手取材、边劳作边唱」成为常态——采槟榔累了敲槟榔叶而歌，砍竹空闲削竹筒而吹。

主要传统乐器：

| 乐器 | 主要流布支系 | 说明 |
| --- | --- | --- |
| 口簧琴（lubuw 等） | 泰雅、阿美等，分布最广 | 音量极低，仅适近距离交谈，在泰雅社会中是**恋人谈心的工具** |
| 弓琴 | 多支系 | 以弓弦振动发声 |
| 鼻笛 | 排湾、鲁凯 | 双管/单管鼻吹，音色幽柔，多用于抒情与仪式 |
| 竹笛、竹筒 | 阿美等 | 取材竹管 |
| 杵与杵音 | 多支系 | 捣粟之杵兼作打击与合唱伴奏，「杵歌」由此得名 |
| 木琴、摇摇器 | 部分支系 | 用于集体歌舞 |

### 1.2 单音体系与复音体系并存

这是高山族音乐最富学术价值的结构特征，也是它区别于绝大多数中国民族音乐之处。学界（如吕炳川、许常惠、吴荣顺等）大体作两分：

**（一）复音／多音性（polyphony）**——最具世界性意义的一支

- **布农族【祈祷小米丰收歌】（pasibutbut，通称"八部合音"）**：高山族音乐的国际名片。1952 年，日本音乐学者黑泽隆朝将此曲录音寄送联合国教科文组织，西方学者听到古老部落竟有如此繁复的和音，震动学界——此前"音乐由单音、双音发展至和音"的进化论式起源说因此被改写。1990 年，吴荣顺正式将其定名为「八部合音」。
  - **发声机理**：演唱时产生自然泛音现象，复音声部会浮出 8 个以上音高；第二声部歌者以舌尖顶上口盖前后形成**双口腔共鸣**的双声技巧（世界上已知能运用双声技巧的民族极少，布农族是其中之一）。
  - **音阶**：刻意去掉 Fa、La、Ti 三音，只保留其余五音。
  - **声部与规则**：实际声部约 3—4 部（mahosgnas、manda、mabonbon、lagnisgnis），依严格规则由低而高缓缓叠入，音域升高时泛音繁出，遂成"八部"之听觉效果。
  - **社会限定**：参与者须是一年中未曾犯错的纯洁男性，排练极为严谨；族人相信合音越和谐、天神越喜悦，当年小米越丰收。此曲与小米播种祭绑定，11—12 月间于家屋前围圈而唱。
- **阿美族**：歌舞音乐特征典型，明朗活泼、旋律性强，音域宽广、节奏鲜明；以**自由对位的复音唱法**最具特色，常用头腔、喉腔唱出悠远绵长的声线，被形容为有"海洋壮阔"的联想。
- **鲁凯族**：单音性与多音性歌谣并存，两类都极具代表性。

**（二）单音体系（monophony）**

- **泰雅族**：以单音旋律为主，有领唱、对唱等多种形式；其口簧琴文化最独特。
- **达悟族（雅美）**：长期居于兰屿，**不用乐器**，保存了最原始的歌唱形态——单音朗诵式为原则，配合独唱、领唱、对唱与异音合唱，被视为古老文化的完整样本。
- 赛夏、邹等支系亦以单音与齐唱为主，邹族于战祭中藉祭歌向战神求取神力与勇气。

### 1.3 功能分类与演唱的社会限定

按功能可分两类：

1. **仪式性音乐**：用于祭神与巫医仪式，演唱者、时间、场合均有严格限定。典型场合包括布农族**射耳祭**（malahodaigian，4—5 月举行，求狩猎与农作丰收，女性禁参与，祭仪后男子以 malastapang「报战功」互相呼应）、赛夏族**矮灵祭**、邹族**战祭**、阿美族**丰年祭**（ilisin）等。
2. **民俗性音乐**：用于岁时节令、劳动生活与休闲，演唱者与时机场合没有严格限制，故体裁数量最丰。如阿美族〈饮酒歌〉〈老人嬉游歌〉、各族〈摇篮歌〉等。

早期高山族音乐对**歌唱者的性别、年龄与身份**有严格限定：有些歌仅男性可唱、有些仅女性可唱；有些歌只有具特定身份地位者才有资格唱。排湾族头目林广财即因幼时家中常有长者吟唱古谣而耳濡目染，习得如今许多人已不会唱的"古调"。

### 1.4 当代变迁

- 17 世纪以来，外来宗教音乐（教会诗歌）、西洋乐器（口琴、吉他最先传入部落）、日据时期的日本音乐语汇、战后英美流行音乐先后渗入，使高山族音乐由"以人声为主"转向"以西洋乐器伴奏为主"。
- 1990 年代中期以后，出现了新的企划与编曲概念，原住民音乐被重新包装，与现代流行音乐元素结合，**不再是原生态的样貌**。
- 与此同时，**"古调"（原始歌谣）正在快速流失**：很多古调连听都没听过的人已占多数，仅少数高龄者仍能吟唱；曲目流传呈现"断层"。

## 二、知名歌手与歌曲的深度研究

高山族音乐的人物谱系可清晰分为三层：**古调传唱者 → 民歌运动一代 → 当代流行与古谣复兴**。三层之间不是替代关系，而是"根—干—枝"的关系。

### 2.1 第一层：古调与第一代传唱者

#### 郭英男（Difang Tuwana，阿美族，1921—2002）与马兰吟唱队

阿美族"国宝级"歌者，音色圆润明亮、能轻松唱到高音声部，被誉为"天生的歌者"。其夫人郭秀珠（Igay Duana）同为主要歌者。

- **1988 年**，夫妇受邀赴法国巴黎参加"太平洋地区原住民舞蹈音乐节"演出，该演出录音被收入法国出版的《台湾原住民复音声乐》（Polyphonies vocales des aborigènes de Taïwan，法国教育部，1988）专辑——**这一"公共出版"成了日后版权争议的源头**。
- **1993 年**，德国 Enigma 乐团在未获授权的情况下，将该专辑中〈饮酒欢乐歌〉（palafang，亦称〈老人饮酒歌〉）的片段采样，混入其作品《Return to Innocence》（返璞归真）。
- **1996 年**，该曲被用作亚特兰大奥运会宣传主题曲，专辑销量逾百万。郭英男本人是在电台听到自己的歌声才知情。
- **1998—1999 年**，在魔岩唱片协助下，郭英男夫妇对作曲者、唱片公司提起诉讼；**1999 年 7 月达成庭外和解**，此后该曲在全球发行中均注明「原音来自台湾阿美族郭英男夫妇」。和解金用于设立奖学金回馈族人。
- **1998 年**发行首张专辑《Circle of Life》，1999 年底发行第二张专辑《横跨黄色地球》，后者获当地金曲奖**最佳民族音乐专辑奖**，郭英男本人亦入围最佳男歌手。

**学术意义**：此案是"口头传统 vs. 著作权制度"冲突的经典个案。民族音乐学者明立国指出，本案暴露了著作权体系与口传文化、与文化传承之间的根本张力——传统歌谣往往被登记为"传统／无著作权"，而其**编曲与演唱**才受保护，这一错位长期损害着原住民歌者的权益。此案之后，相关制度与传统智慧创作保护规则得以修订，音乐界亦开始正视民族音乐的知识产权问题。

#### 陆森宝（卑南族）与〈美丽的稻穗〉

卑南族音乐家，〈美丽的稻穗〉作于 1958 年，是高山族创作歌谣中被传唱最广的一首。胡德夫称之为"我的身份证"。此曲是理解"创作歌谣如何进入民族音乐记忆"的关键样本——它并非古调，却已被各族共认为民族音乐的代表作。

### 2.2 第二层：民歌运动一代

#### 胡德夫（卑南族与排湾族血统，1950— ）

**"台湾民谣之父"**，1970 年代现代民歌运动代表人物之一，与杨弦、李双泽并称"民歌运动三君子"。11 岁离乡赴台北淡江中学就读，在唱诗班与教会圣歌中启蒙；1974 年举办个人作品演唱会，1975 年与杨弦在台北中山堂举行现代民歌演唱会。

- 关键转折：在台北哥伦比亚咖啡厅驻唱英文歌时期，李双泽当众质问他「你是哪一族的？你会不会唱自己民族的歌？」他凭记忆唱出父亲教的〈美丽的稻穗〉，全场起立鼓掌——据其自述"就像台风刮过一样"。由此转向母语歌谣与创作。
- 代表作：〈美丽的稻穗〉〈牛背上的小孩〉〈大武山美丽的妈妈〉〈为什么〉〈太平洋的风〉〈匆匆〉〈最遥远的路〉。
- **2005 年**才发行首张个人专辑《匆匆》（时年 55 岁），在淡江中学小教堂以一架断了弦的 60 年代老钢琴、两天录完，作品被列为当地"流行音乐百佳专辑"第 2 名；2006 年以〈太平洋的风〉获当地金曲奖**最佳年度歌曲**与**最佳作词人**两项大奖。
- 他将自己的音乐风格称为「海洋蓝调」（Hai-Yan Blues），融合卑南语、阿美语等语言韵律。几十年来持续采集、传唱卑南、排湾、阿美等支系的传统歌谣。
- 近年多次在大陆演出与参与两岸音乐交流节目，以〈橄榄树〉〈太平洋的风〉等作品连接两岸听众。

#### 万沙浪（卑南族）与〈娜鲁湾情歌〉

1970 年代以"山地歌王"著称。1988 年央视春晚演唱〈娜鲁湾情歌〉，是大陆听众最早接触的高山族曲调之一。**需要辨析**：该曲曲调确为原住民歌曲，但**国语歌词是后来填写的**。

#### 个案：TBT 泰武古谣传唱——"数据库回流部落"的范例

排湾族古谣合唱团的成立，直接源于音乐采集。吴荣顺在与风潮唱片合作《台湾原住民音乐纪实系列》期间录制了《排湾族之歌》（与江菊妹老师合作），这张唱片成为泰武国小教师查马克·法拉屋乐投入古谣传承的重要契机，进而催生了泰武古谣传唱队。

更值得记录的是出版方的做法：吴荣顺说服风潮，将压制的两千套唱片中的**一千二百套"必须"送回采集录音的部落**，挨家挨户致赠，并坚持每张唱片都附详实的文字背景、歌词与曲谱——使不同族群之间有互相认识学习的素材，部落也有了口传之外的传唱依据。**这套"采集—出版—回流"的伦理框架，正是本课程曲库建设最应参照的范式。**

### 2.4 必须辨析的三个常见说法

1. **〈阿里山的姑娘〉不是高山族民歌。** 它是电影《阿里山风云》的主题歌，属**纯创作歌曲**，长期被误当作高山族民歌传播。
2. **"娜鲁湾"不是地名。** 在高山族语言中它是一个语气助词（衬词），因此歌中出现"娜鲁湾多依呀啦呀吼嗬依呀嘿"这类吟唱并无实义——以为"娜鲁湾"是台湾某地的说法属于误解。
3. **郭英男是阿美族，不是雅美族。** 部分早年报道（含个别大陆媒体旧稿）将郭英男记为"雅美族"，与事实不符；雅美族（达悟）居兰屿，音乐形态为不用乐器的单音朗诵式，与郭英男所属阿美族的自由对位复音体系不同。

**方法论提醒**：流行歌手的**血统出身 ≠ 其作品属于民族音乐体裁**。张惠妹、动力火车、蔡依林（具原住民血统）等人的主流流行作品，不能计入高山族传统音乐范畴；本曲库的检索噪声问题（见第四节）很大程度上正源于此一混淆。

### 3.2 有声出版与田野伦理

### 4.2 本库的入库机制（增的通道）

本项目已把入库沉淀为可复用的技能与脚本（`SKILL.md`，唤醒词「将这个链接入"某某"民族库」）：

- **解析**：支持微信公众号文章／合集／视频专辑、B 站单曲与收藏夹、网易云／酷狗／酷我／咪咕／QQ 音乐六大源；
- **查重**：统一走主程序 `_dedup_key()`（归一化歌名＋歌手口径）与 `_same_recording()`，命中则保留老条目（warm 优先），不重复入库；
- **落盘**：`_ethnos_payload()` + `_atomic_write_json()` 原子写回，并自动在 `versions/` 归档上一版快照；
- **写盘纪律**：直接 import 主程序函数，不另起 `tools_*_ingest.py` 副本（历史上因实现漂移出过死链）；
- **播放自愈**：直链过期由四层自愈链（库内直链 → 按 id 续签 → B 站实时解析 → 四源精确同名重搜）处理，自愈成功的新直链回写曲库。因此**入库时必须保留各源原始 id**（酷我 rid／网易云 song id／QQ mid／B 站 avid）——这是续签的生命线。

## 五、结论与后续计划

1. **音乐本体**：高山族音乐的价值高度集中在**复音体系**，尤以布农族"八部合音"（pasibutbut）的双声技巧与泛音结构为世界级遗产；单音体系（泰雅、达悟等）则保存了更古老的歌唱形态。二者共同构成南岛语系音乐研究的核心样本。
2. **人物谱系**：郭英男—陆森宝（古调与创作源头）→ 胡德夫、万沙浪（民歌运动与大众传播）→ 张惠妹、陈建年、纪晓君、桑布伊、林广财、TBT 泰武古谣传唱（当代流行与古谣复兴）三代接力，构成清晰的传承链条。
3. **知识纠偏**：〈阿里山的姑娘〉非民歌、"娜鲁湾"非地名、郭英男属阿美族而非雅美族——这三条应是课堂讨论的必答项，也是本库关键词设计需要修正的地方。
4. **数据库层面**：本库规模充裕而精度不足。近期动作是**治噪（P0—P2）**，中期动作是**补缺（邵族、拉阿鲁哇、平埔、达悟、赛夏）**，长期动作是建立**支系覆盖率看板**，让"覆盖度"而非"总量"成为曲库健康度的第一指标。
5. **伦理参照**：风潮唱片"采集—出版—回流部落"的做法，以及"每张唱片附歌词曲谱"的规范，应作为本曲库后续扩充与分享的行为准则。
